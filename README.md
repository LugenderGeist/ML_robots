Без нормирования получаются следующие результаты:

При использовании встроенной нормировки StandardScaler получается:

ТРЕНИРОВОЧНАЯ ВЫБОРКА:  
   Accuracy:  1.0000  
   F1-score:  1.0000

ТЕСТОВАЯ ВЫБОРКА:  
   Accuracy:  0.8889  
   F1-score:  0.7500

При добавлении нормировки можно снизить число итераций расчета без потери точности. 
При этом увеличение числа нейронов в слое ухудшает ситуацию, число итераций точность не увеличивает. Увеличение слоев с нейронами также не повышает точность.
Смена StandardScaler на MinMaxScaler привела к снижению точности.
